# Заголовки автомобилей и справочник марок

## Схема данных

`cars.model` остаётся исходной строкой Che168. Новые поля `brand_id`, `model_name`, `model_slug`, `trim` заполняются из справочника и осторожного разбора. При неизвестной марке или модели исходное название остаётся доступным и карточка работает в прежнем виде.

Справочник содержит 19 марок текущей базы и Mazda для будущих объявлений. `name_ru` пока пустой: русские названия марок не требуются в выбранном макете и не вводятся без отдельной проверки. Китайские названия взяты из текущей базы. Для Mazda китайское название в базе отсутствует.

## Порядок развёртывания

1. Сделать резервную копию PostgreSQL обычным способом проекта.
2. Применить `scripts/migrations/20261122_car_titles.sql` к базе сайта.
3. Применить `scripts/migrations/20261122_model_aliases.sql`.
4. Запустить `sudo -u postgres python3 scripts/backfill_car_titles.py` из каталога приложения после установки обновлённых Python файлов.
5. Проверить количество заполненных моделей и список неизвестных серий по выводу скрипта.
6. Опубликовать обновлённый Next.js и заменить рабочий `import_cars.py` вместе с `car_titles.py`.
7. Проверить Jetta VS5, Li Auto L9, фильтры `?brand=jetta` и `?brand=jetta&model=vs5`, а также страницу без `brand_id`.

Миграция должна предшествовать обновлению Next.js и импортера. Обратная миграция `scripts/migrations/20261122_car_titles_down.sql` возвращает старую схему после отката к прежней версии кода. Она удаляет только новые справочники и поля, исходные `cars.model` и `cars.brand_ru` сохраняются.

## Проверка покрытия

По выгрузке активных объявлений от 22 ноября 2026 года для 42 035 из 42 740 строк (98,4%) можно определить модель по справочнику или буквенно-цифровому имени. Это предварительная оценка по префиксу исходной строки, а не результат миграции. `series_name` заполнено у 3 653 строк, поэтому итоговый счётчик следует взять из `backfill_car_titles.py`.

Неизвестные названия марок записываются в `unmapped_brand_names`. Неподтверждённые серии выводятся в отчёт скрипта, без автоматического создания моделей и догадок. Для добавления соответствий дополняют `model_aliases` и повторяют backfill. Редкий текст комплектации на китайском остаётся в исходном `cars.model`, но не выводится как русский перевод.
