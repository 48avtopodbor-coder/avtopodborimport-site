# Фильтры каталога

`/catalog/used` рендерит выборку на сервере. Общие параметры и проверка URL находятся в `src/lib/catalog-filters.ts`, параметризованные запросы — в `src/lib/catalog-data.ts`. API `/api/catalog/list` и `/api/catalog/facets` используют ту же логику. Фасеты кешируются на 300 секунд. Счётчики марок исключают выбранную марку и модели, счётчики моделей — только выбранные модели.

## Данные и миграция

Перед обновлением приложения применить `scripts/migrations/20261123_catalog_filters.sql` к PostgreSQL. Миграция повторяемая и добавляет данные без изменения загрузчика:

- `catalog_spec_bodies` получает тип кузова из `specs.params_json`; триггер обновляет справочник при следующем импорте характеристик.
- Индексы поддерживают кузов, новые поступления и будущую рублёвую цену; существующий индекс `(brand_id, model_slug)` используется для моделей.
- Новая неизвестная марка регистрируется в `brands` с пустым логотипом, попадает в `unmapped_brand_names`; отсутствие логотипа записывается в журнал PostgreSQL. Нормализация названия по прежнему алгоритму переводов остаётся отдельным этапом.
- Используются существующие локальные логотипы; их источники перечислены в `docs/brand-logos.md`. При отсутствии файла показывается буква.

## Цена в рублях

По согласованию фильтр подписан «Цена, ₽». Рублёвой цены сейчас нет: добавлена nullable-колонка `cars.price_rub`, поля отключены с пояснением. Формула не придумана, юани за рубли не выдаются. После утверждения расчёта и заполнения `price_rub` фасеты автоматически разрешат ввод. API фильтрует именно `price_rub`; текущая сортировка «дешевле/дороже» использует существующую цену автомобиля в юанях. Внешний вид и формат цены карточек сохранены.

## Проверка

- URL: несколько моделей/кузовов, диапазоны, сортировка, сброс страницы, Back и серверный HTML по прямой ссылке.
- Безопасность: параметры SQL передаются отдельно, сортировка и поля из белого списка, неправильные диапазоны и URL игнорируются.
- Браузер: 360/640/768/1024/1280px; сетка 1/2/2/3/4; применение черновика, scroll lock, Esc, фон, свайп ручки, возврат и ловушка фокуса.
- Lighthouse Accessibility на локальном каталоге: 96/100. Оставшееся замечание — прежний контраст текста карточек и букв логотипа сайта; их оформление по этому ТЗ сохранено.
- `node --test tests/*.test.mjs`, Python unit tests, ESLint, Prettier и `next build`.

Страница автомобиля, фотогалерея и Python-загрузчик не менялись.
