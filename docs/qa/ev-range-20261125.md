# Catalog model names and electric range — 25 November 2026

Catalog and homepage cards, car breadcrumbs and photo captions use the same mapped model title as the car heading. Original Chinese `cars.model` remains unchanged. The displayed year is the existing `cars.year`, not the model-year code embedded in the source title.

Electric car specifications display the rated electric range from the existing `specs.params_json`, with the reported NEDC/CLTC/WLTC/WLTP cycle. Repeated identical fields are deduplicated. Conflicting values for a cycle, hybrid total range, road-test range and invalid values are not displayed. Missing cycles are explicitly identified. No collector or database migration is required: future imports use the same stored fields.
