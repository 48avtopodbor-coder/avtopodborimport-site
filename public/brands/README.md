# Логотипы марок

Файлы названы по `brands.slug`. SVG должен иметь `viewBox`, прозрачный фон, не содержать скриптов и внешних ссылок и занимать меньше 50 КБ. Для PNG нужен прозрачный фон и достаточное разрешение для плитки 64×64. JPG не используем.

Источники и дата получения указаны в `docs/brand-logos.md`. Названия и изображения остаются товарными знаками правообладателей. Скрипт `node scripts/check-brand-logos.ts` проверяет соответствие справочника файлам. При наличии `DATABASE_URL` он читает марки из PostgreSQL, иначе проверяет начальный список из миграции.
